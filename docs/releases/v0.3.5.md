# Tutorialz v0.3.5

The Android Study tab now includes 24 full chapters, 192 offline sections, 95 worked examples, and 144 self-check questions.

- Every subject includes advanced concepts, production scenarios, exam reasoning, a cheatsheet, and dated references with explicit version baselines.
- All 23 GoF design patterns are covered, including separate Factory Method, Abstract Factory, and Builder examples.
- Search results and chapter contents jump directly to named subtopics.
- Reading progress and bookmarks remain compatible with older backups. Old section numbers retain their original meaning.
- Practice questions and scores are unchanged. The syllabus remains Android-only; the public web app does not bundle it.

Validation includes 35 executable Java 8/9/17/21 programs, 32 API-compiled framework fragments (two also run in a Spring context), and browser checks of all 192 offline reader sections. API compilation does not substitute for database, broker, or full Jakarta-container integration testing. This is independent learning material, not an official Accenture syllabus or assessment reproduction.

The ARM64 APK uses the existing release-signing workflow and Android versionCode 3005. It requires Android 10 or newer. Actual installation on a physical phone has not been tested for this release; retain your progress backup before updating.
