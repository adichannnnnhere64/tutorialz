# Jakarta Dummy Exam

This is a 200-item, original, single-answer practice exam. It is restricted to Java Spring, Hibernate, Jakarta Messaging (JMS), Apache ActiveMQ Artemis, and Java 8 and Java 9. It is practice material, not a copied vendor assessment or a claim of certification equivalence.

| Topic | Questions |
| --- | ---: |
| Java Spring | 40 |
| Hibernate ORM | 40 |
| Jakarta Messaging (JMS) | 40 |
| ActiveMQ Artemis | 40 |
| Core Java — Java 8 | 20 |
| Core Java — Java 9 | 20 |

Each of 50 technical themes has four different outcomes: identify the mechanism, diagnose a mistaken assumption, choose a design boundary, and select a meaningful verification. The exam therefore has 50 recall, 50 debugging, 50 design, and 50 application questions. Questions are original, have four answer choices, explain the answer, and link to the relevant primary documentation.

ActiveMQ questions explicitly target Artemis rather than treating the unrelated Classic and Artemis configuration models as interchangeable. Java questions name their release. Questions carrying framework behavior point to the Spring Framework reference, Hibernate ORM 6.6 guide, Jakarta Messaging 3.1 specification, ActiveMQ Artemis documentation, or Oracle Java API documentation.

Set **Number of questions** to **200** and **Difficulty** to **All difficulties** for the full exam. Catalog revision 3 adds the exam while preserving the existing collection ID and previous question identities.
